REFERENCIA RÁPIDA

Reglas

Números

Se suman solamente los dados del número elegido. Ejemplo: tres seises = 18.

Escalera

1‑2‑3‑4‑5 o 2‑3‑4‑5‑6. Vale 20; con bonus servida, 25.

Full

Tres dados iguales y dos de otro valor. Vale 30; servida, 35.

Póker

Cuatro o cinco dados iguales. Vale 40; servida, 45.

Generala

Cinco dados iguales. Vale 50. Doble generala vale 100 en este preset.
